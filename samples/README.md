# Sample deliverables: Campus Lost & Found

These show the documents that come with a project. They are written for a fictional college, every file is marked SAMPLE, and names in square brackets are placeholders.

| File | What it is |
|---|---|
| [synopsis.pdf](synopsis.pdf) | 3-page synopsis for guide approval, with a literature survey and references |
| [report-chapter-1.pdf](report-chapter-1.pdf) | Chapter 1 (Introduction) of the project report, in a typical university format |
| [presentation.pptx](presentation.pptx) | 6-slide review presentation |
| [viva-questions.pdf](viva-questions.pdf) | 15 likely viva questions with short answers for this project |
| [diagrams/](diagrams/) | Use case, ER, sequence and DFD level 1, as SVG and PNG |

The full report for a real project follows your college's template: certificate, declaration, acknowledgement, abstract, then the chapters.
